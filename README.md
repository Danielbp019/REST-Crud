# Descripción del Proyecto

Este proyecto surge como la integración de varios desarrollos de práctica enfocados en la **arquitectura REST**.  
Cada uno de los servicios implementados comparte la misma **base de datos**, lo que permite que sean totalmente **intercambiables** entre sí.

## Objetivo

El objetivo principal es:

- Evaluar y comparar los **tiempos de respuesta** bajo condiciones equivalentes.
- Analizar la **interconexión** entre los distintos servicios.
- Obtener una visión más clara sobre el **rendimiento**, la **escalabilidad** y la **flexibilidad** de este tipo de arquitecturas.

## Enfoque

En esencia, se trata de un conjunto de **proyectos de práctica** diseñados para:

- Experimentar con el desarrollo de **APIs RESTful**.
- Afianzar conocimientos en la reutilización de recursos.
- Medir resultados en escenarios controlados.
- Utilizar una **base de datos única**, compuesta por una sola tabla.
  - La base de datos se llama **`articulos`**.
  - Puede encontrarse en los proyectos marcados como **Back End**.
  - En el caso de **Laravel**, está definida en las **migraciones**.
